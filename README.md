# TaskFlow Pro — Team Task Manager

## 🚀 Live Demo
**[Click Here to Open App](https://taskflow-pro-production-3b7c.up.railway.app)**

## Features
- Signup / Login with JWT Auth
- Create Projects & invite team members
- Role-based access: Admin / Member
- Task creation with priority & due dates
- Kanban Board (To Do → In Progress → In Review → Done)
- Dashboard with stats & overdue tracking

## Tech Stack
- Node.js + Express
- LowDB (JSON Database)
- JWT Authentication
- Vanilla JS Frontend

## Run Locally
git clone https://github.com/amaanug/taskflow-pro.git
cd taskflow-pro
npm install
npm start
